# resumo-do-lab
Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do lab na DIO
O aprendizado começou com a identificação dos tipos de nuvem existentes e como cada uma delas funciona:
Nuvem Pública: Infraestrutura pertencente a um provedor terceirizado (como a Microsoft) e compartilhada entre múltiplos clientes.
Nuvem Privada: Infraestrutura dedicada exclusivamente a uma organização, mantida no próprio datacenter (on-premises) ou hospedada por terceiros.
Nuvem Híbrida: Combinação de ambientes públicos e privados, permitindo o compartilhamento de dados e aplicações entre ambos para atender a requisitos de conformidade e segurança.
Gestão de Identidade no Microsoft Azure (Entra ID / Active Directory)
Princípio de Menor Privilégio: Conceito de conceder aos usuários apenas as permissões estritamente necessárias para realizarem suas tarefas.
Criação e Gestão de Usuários:
Processo de criação de contas no Microsoft Entra ID (antigo Azure Active Directory).
Diferença entre usuários nativos da nuvem, usuários convidados (Guests/B2B) e contas sincronizadas de um ambiente on-premises.
